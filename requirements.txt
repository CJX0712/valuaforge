# Hand-written `name==version` lines, deliberately NOT the output of `pip freeze`.
# `pip freeze` in a venv records local editable installs as `pkg @ file:///C:/.../...`,
# and such a "lock" cannot be installed on any other machine. A lock that cannot be
# installed is not a lock. (Measured in Phase 0.)
#
# Windows note: if pip fails with `OSError: Missing dependencies for SOCKS support`
# or a 502 tunnel error, add `--proxy "" --index-url https://pypi.org/simple`.
# pip 26 reads a SOCKS source from the Windows registry, so clearing shell
# environment variables alone does not help (pitfall library D).
#
# Every pin below has a win_amd64 + cp313 prebuilt wheel: no source builds, no
# MSVC/cmake required. Verified in Phase 1 (docs/phase1_report.md section A.2).
