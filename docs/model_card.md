# ValuaForge 模型卡（Model Card）

> 作者：**晨星** ｜ 域：**数据估值 / 数据归因（Data Valuation）**
> 本卡只写**已实测**的行为。规格书（`algorithm_spec.md`）是设计依据，本卡是**实测结论**。
> 证据脚本：`../repro/`，逐条可重跑。**引用了却不能重跑，等于不可证伪。**

---

## 1. 一句话

ValuaForge 是一个**可复现、公理可验证**的数据估值系统：它实现了经典 Shapley 家族
（暴力精确 / KNN 闭式 / β-Shapley / TMC / Banzhaf / Influence / Data-OOB），
并提出旗舰估计器 **ValuaFuse**（保真度阶梯代理 + 结构对齐 CRN + 对偶分层排列）。

**当前状态：旗舰在 n=10 的精确真值下不占优。** 详见 §4。

---

## 2. 预期的使用场景

| 场景 | 状态 | 依据 |
|---|---|---|
| 小 n（n≤12）精确数据估值、教学/审计 | ✅ 可用，`2^n` 精确真值可枚举 | V1（闭式解与暴力枚举逐位一致 1.78e-15） |
| **KNN utility 下的任意 n 精确估值** | ✅ **强项**，零重训练 | 锚点 B：KNN-Shapley 闭式解 |
| 中等 n（n≈200）**排序**用途（选数据、清洗） | ⚠️ **当前不推荐**。n=200 名义比值 0.53/0.50，但①无精确真值（参考噪声 0.46）②β 为样本内拟合（L10）⟹ **该数字暂不可引用** | V12/V15 |
| 大 n（n≥1000）精确 Shapley | ❌ 不支持 | 2^n 不可枚举；本系统不做近似声明 |
| 跨模型可迁移的估值 | ❌ **实测不成立**，见 §5 | L-BFGS vs SGD×30 估值向量 L2Rel = 1.43~1.52 |

## 4. 旗舰 ValuaFuse 的真实表现（**不美化**）

### 4.1 基线阶梯（n=10，精确真值，两条轨道一致）

| 方法 | L2Rel（确定性效用） | L2Rel（随机效用） | utility 评估次数 |
|---|---|---|---|
| oracle_shuffle（负控制） | 1.5026 | 1.4689 | 0 |
| random_vector（负控制） | 18.62 | 16.37 | 0 |
| constant_vector（退化） | 17.59 | 19.05 | 0 |
| LOO | 0.8932 | 0.8258 | 11 |
| **β-Shapley(1,4)** | **0.7646** | **0.8199** | 1810 |
| TMC tuned（24 组网格） | 0.9332 | 0.9665 | 1811 |
| **ValuaFuse** | 0.9608 | 0.9964 | 2000 |

**最强基线是 β-Shapley(1,4)，不是 TMC。** 这与"教科书默认最强基线是 TMC"的假设**相反**。

### 4.2 等预算 / 等排列数两种口径下，β-Shapley 都最强

| 口径 | β-Shapley | TMC | ValuaFuse | ValuaFuse 比值 | 判定(≤0.75) |
|---|---|---|---|---|---|
| **A 等评估预算**（≈1800 次全保真等价） | **0.7470** | 0.9046 | 0.8638 | **1.1563** | ❌ FAIL |
| **B 等排列数**（各 20 排列） | **0.7683** | 1.4101 | 0.8699 | **1.1323** | ❌ FAIL |

> **口径唯一权威**：`repro/_logs/scale_and_budget.txt`（脚本 `repro/audit_scale_and_budget.py`）。
> 本卡此前一版曾写 0.8625 / 0.9517 与 1.1546 / 1.2387 —— **已作废**，
> 那是同脚本更早一次运行的输出，未随重跑更新。**引用前先核对日志。**

⟹ **"β-Shapley 赢只是因为它便宜"这个解释被排除**：它在两种口径下都最强。

**预算口径必须双报**（口径 A 的实测）：
| 方法 | L2Rel | raw 调用 | 全保真等价 |
|---|---|---|---|
| β-Shapley | 0.7470 | 1810 | 1810 |
| ValuaFuse | 0.8638 | **5160** | 1892 |

ValuaFuse 的 **raw 调用是 β 的 2.8 倍**，但全保真等价只多 4.5%——因为多出来的调用大多是廉价的。
**用调用数当预算会误判它更贵，用等价成本当预算会误判它更便宜。两个口径都必须报。**

> 🔺 **更根本的一条（L8）**：预算是 `utility.evaluate` 的**调用次数**，
> 代理与目标**各记 1 单位** ⟹ "把预算挪给便宜代理"这个前提**在预算口径下恒为 1.0×**，
> **根本不可度量**。在 KNN 轨道上代理墙钟反而**贵 2.77×**。
> ⟹ **KNN 赛道上不得声称 ValuaFuse 更快或更省**（I27 门禁）。

### 4.3 规模依赖（n ≤ 12，**不外推到 n≥200**）

3 个种子 {777, 2026, 31337}，每个 n 都用精确真值：

| n | 最强基线 L2Rel | ValuaFuse L2Rel | 比值均值 | 比值范围 | 判定 |
|---|---|---|---|---|---|
| 8 | loo 0.359~0.484 | 0.455~0.730 | **1.2561** | 0.9950~1.5079 | ❌ |
| 10 | tmc/loo 0.500~0.620 | 0.500~0.735 | **1.0599** | 0.9659~1.2315 | ❌ |
| 12 | tmc/loo 0.582~0.645 | 0.582~0.733 | **1.0359** | 0.9680~1.1358 | ❌ |

> **权威来源**：`repro/_logs/scale_and_budget.txt`。本卡前一版曾写 1.2732 / 1.0728 / 1.0790
> 与"非单调（n=12 回升）"的结论 —— **已作废**，那是同脚本更早一次运行的输出。
> **权威版本是单调下降的**（1.2561 → 1.0599 → 1.0359）。

**ValuaFuse 在 n=8/10/12 的任何一个、任何一个种子下都没有达到 0.75。所有比值 > 1.0。**

> **撤回一个先前结论**：单种子运行时 n=12 曾出现 0.7278（PASS）。多种子复跑后该点为
> 0.968 / 1.004 / 1.136（均值 1.0359，FAIL）。**原 PASS 是种子运气，特此撤回。**

**预先登记的判据「均值随 n 单调下降」：满足**（1.2561 → 1.0599 → 1.0359；
最坏种子口径同样满足）。逐种子离散度亦随 n 收缩（**0.513 → 0.266 → 0.168**）。

**但趋势方向正确不等于达标**：均值比值始终 > 1.0，**没有任何 n、任何种子达到 0.75**
（最好 n=12/seed777 = 0.9680）。**比值在向 1.0 收敛，而不是向 0.75。**

**β̂ 随 n 不单调但恒为正**（9 个值全在 +0.43 ~ +0.49），
因此"控制变量随规模变好"**不是**该趋势的解释。**机制判定：见 §4.4（预算配置，非 CV 失效）。**

### 4.4 失败原因（**已修正；前一版结论作废**）

> **方差缩减无法补偿"把预算挪去廉价代理"造成的全保真样本损失。**

**控制变量本身是有效的**：修正实现后，交叉拟合 β̂ 在全部 9 组 (n, seed) 配置中
**一致为正**（**+0.43 ~ +0.49**），说明 CV 确实在按预期降噪。

**真正的原因是预算配置**：

| 方法 | 全保真排列数 | 廉价排列数 | 全保真等价成本 | L2Rel |
|---|---|---|---|---|
| β-Shapley(1,4) | **181** | 0 | 1810 | **0.7470** |
| ValuaFuse | **86** | 86 | 1892 | 0.8638 |

在 n ≤ 12 且**全保真效用本身很便宜**（L-BFGS）时，把一半预算分给廉价代理
**直接损失了一半的全保真信息量**。控制变量能降低"已有全保真样本"的方差，
**但造不出新的全保真信息**。于是比值卡在 ≈1.04~1.16。

> **⚠️ 撤回前一版结论**：本卡此前写「β̂ = −0.610 / −0.139（为负）→ 控制变量在加噪」。
> **作废。** 该数字来自实现 bug——交叉拟合本应按**排列**切分，我却先聚合成
> 长度 n 的向量再切片，n=10 时 `slice(86, None)` 落在 10 元素数组上得到**空切片**，
> Var(dY)=0。修正后 β̂ 全部为正。**这正是"负结果/异常结果必须先怀疑自己的实现"的又一例。**

**可迁移的判据**：方差缩减在「全保真评估昂贵」时是净收益；在「全保真评估廉价」时，
**同样的预算应全部留给全保真采样**。

**这不是实现 bug**（I1–I27 全部通过）；是方法在该规模下的**预算配置**边界。

### 4.5 由此得出的使用建议

1. **小 n 下不要用 ValuaFuse**，用 **β-Shapley(1,4)**（更便宜且更准）。
2. 启用 F1 前**必须**检查交叉拟合 β̂ 的**符号**（正确实现下应 > 0）；β̂ ≤ 0 说明实现或代理有问题。
3. **更根本**：先判断全保真评估是否昂贵。若廉价（全保真 utility 便宜），**把全部预算留给全保真采样**，不要分给代理。
4. 报告预算时**同时给 raw 调用数与全保真等价成本**（实测 ValuaFuse raw 5160 / 等价 1892，而 β-Shapley 1810 / 1810）。

## 5. 已知限制（逐条实测，无推测）

| # | 限制 | 实测依据 |
|---|---|---|
| L1 | **跨效用可迁移性不成立** | full-LBFGS 与 SGD×30 的估值向量 L2Rel = 1.4281 / 1.5190 |
| L2 | **n=200 无精确真值** | 参考真值自身 split-half L2Rel = 0.4576 / 0.4531，**只有比值可比** |
| L3 | **ρ̂ 依赖测量协议** | 独立排列下 ρ̂ 上限 ≈ 0（同一代理与自己比 ρ = −0.0081）⟹ 必须用共享排列 |
| L4 | **DoD 是规模条件化的** | n=8/10/12 全部 FAIL（1.2561 / 1.0599 / 1.0359）；n=200 名义 PASS 但口径不干净（见 L10），**三者不可互相外推** |
| L5 | 未在真实大规模数据（MNIST/CIFAR）上评测 | 本项目只用合成 DGP |
| L6 | 未实现 CS-Shapley / δ-Shapley | **因此不能声称"全面超越 SOTA"** |
| L7 | CRN 在**确定性效用**下完全失效 | 确定性 utility 无训练随机性可抵消；此时只有 F1+F3 生效 |
| L8 | 🔺 **预算货币测不出"便宜"——旗舰的经济前提在 KNN 赛道上不成立** | 实测单次调用墙钟：`knn` 67.21 / `sgd` 185.94 µs（**代理贵 2.77×**）；但预算是 `utility.evaluate` 的**调用次数**，代理与目标**各记 1 单位** ⟹ `c = cost(代理)/cost(目标)` 在预算口径下**恒为 1.0×，根本不可度量**。⟹ **KNN 赛道上不得声称 ValuaFuse 更快或更省**（I27 门禁，`algorithm_spec.md` §4.7） |
| L9 | **`logreg` 效用下所有置换类方法不可用** | 单类子集 `v(S)` 无定义（抛 E303，规格 §2.1.1 已裁定为契约），而任何排列必经单点联盟 ⟹ ValuaFuse / TMC / β-Shapley **必然中途抛错**。这不是缺陷，但**使用者必须知道**：本仓的置换类估值只在 KNN 轨道上可运行 |
| L10 | **n=200 的"通过"口径不干净** | `calibrate_n200.py` 的 β 为**样本内拟合**（β→0.9996），使 φ̂ ≈ 两噪声之差。隔离实验：in-sample β=0.9996 / cross-fit β=0.8411，比值 1.1883。**重跑前不引用该数字** |

## 6. 伦理与使用边界

- 本系统输出的是**估值排序**，不是因果效应。**高估值 ≠ 该点对下游有因果贡献**。
- 噪声检测（低分端）**不是**异常检测的替代品，二者混淆会产生误伤。
- 自动剔除低估值数据**可能**移除少数群体的关键样本；DGP-3（`RareSubgroup`）
  正是为此设计——**LLM/单点移除在该 DGP 上必然失效**。
